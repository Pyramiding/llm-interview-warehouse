## 业务链路与阅读方式

先沿“数据与标签 → 表征/模型 → 候选与策略 → 在线执行 → 结果与反馈”定位瓶颈，再看评测、成本和失败恢复。每题可用一个真实但去标识的项目回答；没有线上实验时明确区分离线能力与业务增量。

## 系统链路：数据、基线、机制与验收

下表是可供面试设计的原创工程拆解；每个环节需用实际约束验证，不能由单个离线指标推断业务收益。

| 环节 | 数据 / 标签 | 传统基线 | LLM 结合机制 | 评测 / 成本 |
|---|---|---|---|---|
| 资格与授权 | 订阅、退订、渠道资格、时间 | 规则引擎与黑白名单 | 只解释资格原因，不授予资格 | 错误触达率；检查延迟与审计量 |
| 受众表征 | 处理前行为、文本证据、标签有效期 | LR/GBDT、分群 | 离线文本标签与embedding蒸馏 | 标签精确率/覆盖；每千人处理成本 |
| 商品匹配 | 库存、价格、商品与人群交互 | 双塔召回、Wide & Deep排序 | 商品卖点结构化与语义匹配 | Recall/NDCG及库存有效率；在线p99 |
| 内容生产 | 商品事实、品牌规范、历史人工素材 | 模板与规则填槽 | SFT风格、受约束生成、多语言 | 事实错误/条款完整；每通过审核素材成本 |
| 素材审核 | 政策版本、人工双标、风险类型 | 词典/分类器/规则 | 语义审核和证据定位 | 高危漏检、误杀与人工工时 |
| 触达分配 | 动作概率、渠道成本、随机留白 | uplift、约束优化、bandit | 文本表征支持冷启动，不替代因果估计 | 增量毛利减成本；退订/频控护栏 |
| 渠道执行 | 送达状态、活动截止、幂等键 | 消息队列与发送平台 | 摘要与异常诊断辅助 | 重复/过期发送、送达时延与渠道费用 |
| 归因反馈 | 曝光、点击、成熟购买、退货 | 随机抑制、归因报表 | 触点文本整理、失败聚类 | 留白增量及置信区间；返工成本 |

## 项目验收证据清单

提交设计或复盘时，至少准备以下可核查材料；不提供内部数据和个人信息。

1. 一份冻结的活动brief、商品/价格版本、授权受众和跨渠道频控配置。
2. 一份带处理前特征、动作概率、未触达留白和成熟结果的去标识样本字典。
3. 四组消融：规则/通用内容、受众优化、内容优化、二者组合；给预算与置信区间。
4. 素材事实审查、过期发送、重复发送、退订与投诉的失败回放。
5. 按增量订单核算生成/审核/渠道/人工成本；写明何时停止活动和回滚。

## 原创题与深入追问

### MA01. 营销系统中 LLM 应放在哪一层？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 把受众筛选、商品匹配、素材生成、审核、渠道编排和归因分开。传统 LR/GBDT/深度排序仍承担高吞吐概率预测，LLM 可离线提取商品卖点和用户授权文本语义，再蒸馏成在线特征；实时生成只覆盖有充分价值与时延预算的请求。固定相同库存、触达资格与预算比较新增收益。
- **深入追问：** 离线生成每天更新，价格每小时变化怎么办？
- **常见误区：** 把会写文案等同于能做好营销分配。
- **一手参考 / 适用边界：** [The Benefits of Controlled Experimentation at Scale](https://www.microsoft.com/en-us/research/publication/the-benefits-of-controlled-experimentation-at-scale/)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA02. 怎样建立受众标签而不让模型臆造用户属性？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 定义标签语义、证据字段、有效期和未知值；只使用获得授权且与任务相关的信息。让 LLM 输出可回溯证据片段与受限标签，抽样双人复核；低置信与相互矛盾进入未知或复核。训练小分类器批量预测，观察各人群精确率与覆盖，避免从措辞推断敏感身份。
- **深入追问：** 一句购买意向能保留多久？
- **常见误区：** 把生成的用户画像直接当真实标签。
- **一手参考 / 适用边界：** [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA03. 高转化受众与高增量受众为何不同？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 转化率预测回答谁会买，CATE 回答触达相对不触达改变多少。定义处理、观察窗与随机留白，比较 S/T/X-learner，并检验重叠性与组间平衡；文本 embedding 只能作处理前协变量。优先按预期增量毛利扣触达成本分配，不能以模型语言解释替代因果识别。
- **深入追问：** 老客本来就会购买，优惠券是否浪费？
- **常见误区：** 按购买概率排序并命名为 uplift。
- **一手参考 / 适用边界：** [Meta-learners for Estimating Heterogeneous Treatment Effects using Machine Learning](https://arxiv.org/abs/1706.03461)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA04. 多渠道、多文案如何组织训练样本？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 以用户在决策时刻的可用状态为特征，记录候选渠道、实际动作、分配概率、送达和结果。把推送、短信、邮件视为不同处理并保留未触达对照；内容版本哈希连接到素材审核记录。按用户和时间切分，禁止把点击后的会话或最终归因标签带回特征。
- **深入追问：** 送达失败属于哪个实验组？
- **常见误区：** 删除失败发送样本造成选择偏差。

### MA05. 如何把品牌风格 SFT 与商品事实分开？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** SFT 学表达结构、语气与禁止措辞；价格、库存、优惠条件从版本化商品服务注入。训练集按商品族与活动划分，去除近重复；验证新商品可迁移性和条款完整性。输出结构化槽位再渲染，多语言分别验收，不让风格偏好覆盖事实约束。
- **深入追问：** 品牌偏好和最新活动规则冲突怎样处理？
- **常见误区：** 把昨天的优惠训练进参数并当实时事实。
- **一手参考 / 适用边界：** [Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA06. 如何评价创意质量而非只看流畅度？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 建立事实正确、品牌一致、可读性、差异性、合规与实际表现的分层指标。人工盲评使用相同 brief，裁判模型仅辅助筛选，检测长度与自偏好；线上随机展示素材，固定曝光位置和受众。报告点击到购买、退订、投诉与退货，避免夸张内容换点击。
- **深入追问：** CTR 上升但退货增加该怎么解释？
- **常见误区：** 以模型打分高宣称营销效果好。

### MA07. 如何控制素材生成的组合爆炸？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 将商品、受众、渠道和语言分层，先生成共享商品事实与模板，再对高价值组合少量扩写。缓存键含商品/规则版本与风格版本，过期失效；离线批处理、长度上限、去重与小模型审核控制成本。计算每个通过审核素材和每个增量订单的总成本，包含人工复核。
- **深入追问：** 百万组合只有少量真实曝光，预算怎样用？
- **常见误区：** 只报每 token 费用忽略低利用率。
- **一手参考 / 适用边界：** [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA08. 营销 bandit 能代替 A/B 吗？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** Bandit 优化探索期收益但会改变样本分配，分析要记录动作概率并处理非平稳性。固定留白组评估总体增量，约束退订率与渠道频控；LLM 文案特征可帮助冷启动，但未曝光文案的表现仍未知。区分选择策略评估与某条创意的因果结论。
- **深入追问：** 新素材不断进入，如何保留可解释对照？
- **常见误区：** 把自适应分配后的均值直接相减。
- **一手参考 / 适用边界：** [The Benefits of Controlled Experimentation at Scale](https://www.microsoft.com/en-us/research/publication/the-benefits-of-controlled-experimentation-at-scale/)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA09. 最后点击归因为什么不等于因果贡献？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 末次点击只是一种记账规则，受渠道位置、观察窗和用户自选择影响。用随机抑制、地理实验或合适的准实验估计增量，并明确干扰与外推条件；多触点模型服务描述与分摊，不自动证明每次触达创造价值。LLM 可以整理触点文本，不应凭故事分配因果权重。
- **深入追问：** 品牌搜索承接了自然需求如何估值？
- **常见误区：** 用更复杂归因模型消除全部混杂。

### MA10. 频控与触达时机怎样建模？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 维护跨渠道用户级状态，区分候选、发送、送达与实际可见。先用硬频次、免打扰与退订规则过滤，再在可行动作中优化增量收益；把历史曝光与疲劳作为状态，评估短期收益和后续退订。LLM 的时机建议必须受策略服务约束，不能绕过资格与频控。
- **深入追问：** 多个活动同时争取同一用户怎么办？
- **常见误区：** 各渠道局部优化却累计过度打扰。
- **一手参考 / 适用边界：** [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA11. 如何设计新商品、新人群的冷启动？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。

### MA12. 怎样应对生成内容的事实与承诺错误？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 关键条款从结构化数据复制，金额、日期、适用范围用确定性校验。审核分素材风险等级，记录生成输入、模型、证据和人工修改；违规素材隔离并追溯缓存。评价漏检与误杀成本，低风险表达可自动通过，复杂承诺转审核，不让模型自行批准。
- **深入追问：** 文案写了不存在的退款承诺怎样发现？
- **常见误区：** 只用关键词黑名单覆盖事实错误。

### MA13. 怎样研究个性化文案是否有真实价值？

### MA14. 营销在线链路如何降级？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 在线服务只消费审核通过且未过期的素材 ID，规则服务掌握资格、库存和频控。超时使用已批准通用素材或跳过发送，幂等键避免重试重复触达；队列设置截止时间，过期活动禁止补发。观测生成、审核、排队、渠道送达各阶段延迟。
- **深入追问：** 促销已结束但发送队列未清空怎么办？
- **常见误区：** 超时后无条件重试直到成功。
- **一手参考 / 适用边界：** [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA15. 离线 uplift 评价如何避免自欺？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 在随机保留测试集上按预测增量分桶，计算处理与对照差异并给置信区间；Qini/AUUC 只是排序摘要，需说明归一化与样本权重。估计策略价值时明确 propensity 与支持集，检查小概率权重和交叉拟合。最终仍以受约束线上留白检验。
- **深入追问：** 两个策略 AUUC 接近但成本不同如何选？
- **常见误区：** 把个体未观测反事实当真实监督标签。

### MA16. 怎样分析营销模型的漂移？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 分别监测商品结构、受众组成、渠道可达、语言风格与标签成熟度；按活动和时间看校准而非只看全量均值。保留静态对照与模型版本，节假日先定位环境变化，再判断是否重训；新的生成风格可能改变点击分布，需重评下游预测。
- **深入追问：** 大促前后转化先验变化怎么修正？
- **常见误区：** 将所有线上下降归咎于基座能力不足。
- **一手参考 / 适用边界：** [On Calibration of Modern Neural Networks](https://arxiv.org/abs/1706.04599)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA17. 项目深挖时怎样说明自己的增量贡献？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 按问题、基线、个人模块、数据与实验、失败案例和成本逐项讲。区分受众策略、内容和渠道改造，给同条件消融及线上置信区间；说明人工投入和上线限制。遇到归因不清时直接承认，不能把团队业务增长全部归给模型。
- **深入追问：** 没有足够流量做实验时能提出什么结论？
- **常见误区：** 以活动 GMV 变化作为模型因果收益。
- **一手参考 / 适用边界：** [The Benefits of Controlled Experimentation at Scale](https://www.microsoft.com/en-us/research/publication/the-benefits-of-controlled-experimentation-at-scale/)；参考其机制或评价框架，具体业务方案与阈值需另行验证。

### MA18. 开放设计：有限预算下做跨渠道新品营销？

- **难度 / 适用岗位：** 中高级至高级；营销算法、增长科学、应用系统。
- **原创作答要点：** 先定义可触达资格、增量毛利、退订护栏与库存约束。离线构建语义特征和审核素材库，在线以增量评分分配渠道并做全局频控；留随机对照，分阶段探索新品。提交容量预算、状态表、故障降级和实验方案，解释何处用传统模型、何处用 LLM。
- **深入追问：** 预算减半先砍生成量还是触达量？
- **常见误区：** 只画一个自动营销 Agent 而没有分配和测量机制。
- **一手参考 / 适用边界：** [Meta-learners for Estimating Heterogeneous Treatment Effects using Machine Learning](https://arxiv.org/abs/1706.03461)；参考其机制或评价框架，具体业务方案与阈值需另行验证。
