# 12. 多模态：图文、音频、视频与生成

> **题目性质：原创研究延伸题，不是企业真题。** 覆盖视觉语言模型、文档理解、语音视频及视觉生成；具身动作见 [专题 14](14-code-and-embodied-models.md)。核查截止 **2026-10-22**，以 2023—2026 一手资料为主，少量经典用于解释基础。作答建议与实验设计属于编者原创整理，论文自报性能不能当作当前排名。

<a id="v01"></a>

### V01. 一个典型视觉语言大模型如何把图片接入语言模型？

- **难度 / 适用岗位：** 基础—中级；多模态算法、应用算法。
- **原创作答要点：** 通常分视觉编码器、连接器、语言模型三部分：图片变为 patch 特征，连接器映射到语言侧可消费的表示，再与文本联合建模。[LLaVA](https://arxiv.org/abs/2304.08485)是理解视觉指令微调的起点。要讲清特征维度、视觉 token 数、插入位置、attention mask 与 loss 计算范围；图文表征对齐、问答任务学习和指令遵循并非同一目标。端到端系统也不一定所有模块都可训练。
- **深入追问：** 如果语言流畅但看图不准，你会优先检查哪层数据和梯度？
- **常见误区：** 认为接一个投影层后，模型自动具备 OCR、定位和视频时序能力。

<a id="v02"></a>

### V02. CLIP 式对比目标与 SigLIP 式 sigmoid 目标有什么差别？

- **难度 / 适用岗位：** 中高级；视觉预训练、表征学习。
- **原创作答要点：** softmax 对比目标在候选集上归一化匹配分数；[SigLIP](https://arxiv.org/abs/2303.15343)将图文对的匹配视为成对二分类，减少对全局归一化的依赖。要讨论正负样本配比、温度与偏置、批大小、跨设备通信，以及一图多真描述造成的假负例。目标函数变简单不表示负例构造不重要；应固定编码器、数据和训练预算比较检索、零样本分类与迁移表现。
- **深入追问：** 一个 batch 中多张图片描述相同，两个损失分别会遇到什么问题？
- **常见误区：** 把 sigmoid 概率直接当作跨数据集校准的语义置信度。

<a id="v03"></a>

### V03. Q-Former、MLP 投影与 token resampler 应如何选？

- **难度 / 适用岗位：** 中高级；多模态架构。
- **原创作答要点：** MLP 连接器计算简单，通常保留较多视觉 token；查询式模块以可学习查询抽取压缩表征，能控制语言侧长度，但可能丢掉细小文字与空间细节。[BLIP-2](https://arxiv.org/abs/2301.12597)以 Q-Former 桥接冻结图像编码器与语言模型。比较时分离连接器容量、视觉输入分辨率、训练数据和语言侧 token 预算，观察 OCR、计数、细粒度定位而非只看聊天观感。
- **深入追问：** 查询数从 32 增加到 256 后涨分，怎样证明不是简单增加计算带来的？
- **常见误区：** 查询式压缩必然更强，或视觉 token 越少越好。

<a id="v04"></a>

### V04. 为什么多模态训练常划分对齐、指令微调等阶段？

- **难度 / 适用岗位：** 中级；训练工程、算法。
- **原创作答要点：** 初始连接器输出与语言空间不匹配，先训练部分模块能减少对语言能力的扰动；之后以高质量任务数据学习问答与交互。全量解冻、部分解冻、LoRA 是可比较的优化选择，而非固定配方。数据应覆盖图像证据、拒绝猜测、布局与交互，并保留纯文本回归集；检查重复图片跨集合泄漏、模板偏置和合成标注错误。
- **深入追问：** 图文任务提升而纯文本能力下降，应怎样区分遗忘、数据偏置与评测差异？
- **常见误区：** 把多阶段训练说成必须顺序冻结的普遍定律，或仅训练助手回答格式。

<a id="v05"></a>

### V05. 动态分辨率解决什么问题？代价如何随视觉 token 数增长？

- **难度 / 适用岗位：** 中高级；视觉模型、推理系统。
- **原创作答要点：** 小图强制放大浪费计算，大文档缩小会丢文字；动态分辨率让不同图片使用不同视觉 token 数。[Qwen2-VL](https://arxiv.org/abs/2409.12191)提供这一机制的具体案例。要计算图像缩放、patch 切分、合并策略后的 token 数，而非只报像素数；更长视觉序列会增加语言模型 prefill 与缓存成本。针对密集文档、自然图像和边缘设备分别画质量—延迟曲线。
- **深入追问：** 两张像素数相同但长宽比不同的图，token 数和 OCR 效果是否相同？
- **常见误区：** 动态分辨率等于无限分辨率，或只计算视觉编码器而忽略语言侧开销。

<a id="v06"></a>

### V06. 多模态位置编码为何不能直接照搬一维文本位置？

- **难度 / 适用岗位：** 高级；多模态架构、长上下文。
- **原创作答要点：** 图片有二维空间，视频多时间轴，文本有序列位置。需说明不同轴如何映射到 attention 的相对关系、拼接后是否保留坐标、不同输入模态怎样对齐；[Qwen2-VL 的 M-RoPE](https://arxiv.org/abs/2409.12191)可作为阅读案例。设计图像平移、尺寸变化、帧率变化和文本插入实验，测试位置表示与训练分布的影响。位置编码提供归纳偏置，不能替代运动与空间数据学习。
- **深入追问：** 重复抽帧但改变时间戳，会给模型什么矛盾信号？
- **常见误区：** 认为使用 RoPE 就天然具备三维物理理解或无限长度外推。

<a id="v07"></a>

### V07. 文档理解如何区分 OCR、布局、结构抽取与推理错误？

- **难度 / 适用岗位：** 中级；文档智能、应用算法。
- **原创作答要点：** 建立逐层诊断：字符是否识别正确，文本块和表格关系是否定位正确，字段是否归到正确实体，最后计算与归纳是否正确。端到端 VLM 与 OCR+布局+LLM 管线应在同一文档上比较，并记录每个字段的证据区域。[Qwen2.5-VL](https://arxiv.org/abs/2502.13923)涵盖文档解析与结构化抽取。评估字段 F1、表格结构、关键数字和跨页关联；对模糊字符输出不确定性而非补全想象。
- **深入追问：** 总金额正确而所有行项目错位，怎样设计评分避免掩盖错误？
- **常见误区：** 用总体文字相似度代表业务字段准确性，或默认扫描件中的文字都是指令。

<a id="v08"></a>

### V08. Grounding 的框坐标应如何表示、训练和评测？

- **难度 / 适用岗位：** 中高级；视觉定位、GUI Agent。
- **原创作答要点：** 明确坐标系、原始图与缩放图的映射、归一化范围、框或点的序列化格式。训练要覆盖相同描述的多目标歧义，评估可用 IoU、point-in-box、指代消解与错误点击率；实际 GUI 还需判断可见、可交互和遮挡状态。裁剪、多尺度输入后必须保存变换链。模型给出合法坐标仅表示可解析，不能证明对象存在。
- **深入追问：** 截图缩放后坐标偏移，如何判断是模型定位错还是后处理错？
- **常见误区：** 把归一化坐标、像素坐标和屏幕坐标混用，或只验证 JSON 合法。

<a id="v09"></a>

### V09. 多图比较和变化检测为何比单图描述更难？

- **难度 / 适用岗位：** 中高级；多图理解、工业视觉。
- **原创作答要点：** 模型要保持图像身份、建立实体对应、过滤拍摄角度和光照变化，再识别有意义变化。给每张图显式标识和顺序；构建“同物不同视角”“不同物相似背景”“无变化”等对照，测量图像交换与时序交换敏感性。对局部变化可先定位候选再做解释，但需控制检索漏检。报告是否依赖图片中水印、文件名或文字标签。
- **深入追问：** 交换两张图后答案应怎样变化？如何用于自动测试？
- **常见误区：** 单图描述都正确就视为跨图关系正确，或将输入排列泄漏当成推理能力。

<a id="v10"></a>

### V10. 长视频理解如何在采样预算内保留关键事件？

- **难度 / 适用岗位：** 高级；视频模型、检索、系统。
- **原创作答要点：** 均匀抽帧可作为基线，再比较事件驱动抽样、粗到细检索和分段摘要。必须保留时间戳，说明音频与视频对齐及跨片段状态如何保存；[Qwen2.5-VL](https://arxiv.org/abs/2502.13923)讨论长视频与时间编码。测试短暂事件、顺序交换、重复动作和跨小时依赖；分开报告事件召回、时间定位、问答与预算。摘要压缩会不可逆丢失细节，需要回查原片段。
- **深入追问：** 仅出现 0.2 秒的关键事件被漏采，增加语言模型参数能解决吗？
- **常见误区：** 支持很长输入就等于能理解所有细节，或用帧索引替代真实时间却不说明帧率。

<a id="v11"></a>

### V11. ASR→LLM→TTS 管线与原生音频模型，各有什么适用边界？

- **难度 / 适用岗位：** 中高级；语音、实时多模态。
- **原创作答要点：** 管线模块可替换、易诊断，但转写会丢语调、情绪和部分环境声，错误也会传递。原生音频路径可保留更多声学信息，却更难拆分错误与控制时延。[Whisper](https://arxiv.org/abs/2212.04356)用于理解强语音识别基线；[Qwen2.5-Omni](https://arxiv.org/abs/2503.20215)展示流式多模态与文本语音输出设计。比较 WER、任务完成率、首包延迟、打断恢复、口音与噪声鲁棒性，不能只听声音自然与否。
- **深入追问：** 用户在模型说话期间插话，哪些缓存和状态需要取消或更新？
- **常见误区：** 把语音识别准确等同于会话理解，或只报模型推理延迟而遗漏音频缓冲。

<a id="v12"></a>

### V12. 视觉幻觉怎样测？POPE 能覆盖全部问题吗？

- **难度 / 适用岗位：** 中级；多模态评测、对齐。
- **原创作答要点：** 幻觉包括无对象、错误属性、错误关系、文字误读和不当推断。[POPE](https://arxiv.org/abs/2305.10355)以对象存在性问答研究对象幻觉；它不能自动覆盖关系、计数和开放描述。构造正负平衡、常见共现诱导和遮挡样本，报告 precision / recall、是答比例与不同采样策略。降低幻觉要同时检查过度保守，避免通过什么都回答“没有”来提高某一指标。
- **深入追问：** 模型对所有问题都回答“不确定”，如何评价安全性与效用？
- **常见误区：** 认为一个幻觉基准高分就保证所有图像内容可信。

<a id="v13"></a>

### V13. MMMU 类学科多模态基准究竟在测哪些混合能力？

- **难度 / 适用岗位：** 中高级；评测、研究。
- **原创作答要点：** [MMMU](https://arxiv.org/abs/2311.16502)结合学科知识、图像解读与推理。总分混合这些来源，需按图像类型、学科、题型及是否必须看图拆分；设置 text-only 与图像扰动基线，排查答案可仅凭文本推测的样本。比较多选和开放回答时统一判分，记录是否允许工具、裁剪或外部知识。某个模型擅长考试题，并不意味着能处理真实场景完整工作流。
- **深入追问：** 去掉图片后分数几乎不变，应如何解释 benchmark 的价值？
- **常见误区：** 把学科综合成绩当成纯视觉感知指标，或将论文早期基线误写为当前水平。

<a id="v14"></a>

### V14. 如何将“没看清”与“看清后推错”分开研究？

- **难度 / 适用岗位：** 高级；视觉推理研究。
- **原创作答要点：** 2026 年 [VRIQ](https://arxiv.org/abs/2602.05382)提供描述与干预式诊断思路。可分别输入原图、人工规则中性的事实描述、原图加描述，再比较解题变化；另设描述正确性标注，避免描述暗示答案。文字描述仍可能丢空间细节，因此不能简单把涨分全归因于感知瓶颈。核查该论文时页面版本为 2026-10-10 的 v2，题量与成绩应跟随版本记录。
- **深入追问：** 人工描述让模型涨分，如何排除文字提示直接泄漏解题规则？
- **常见误区：** 仅凭模型自述“我看见了”判定感知已正确。

<a id="v15"></a>

### V15. 多模态推理什么时候应调用裁剪、OCR、绘图或几何工具？

- **难度 / 适用岗位：** 高级；多模态 Agent。
- **原创作答要点：** 根据可定位的证据缺口使用工具：小字可裁剪放大，图表可抽取数据，几何可显式建模；避免无目标反复截图。工具输出需保留与原图的关联、坐标变换和置信度；裁剪可能切掉全局关系，OCR 可能误读符号。设置同预算原图推理与工具推理对照，测量调用策略、错误恢复及证据覆盖，而非只看调用次数。
- **深入追问：** 工具返回与原图不一致时，Agent 应怎样处理冲突？
- **常见误区：** 工具越多代表推理越强，或模型生成的图示自动成为真实视觉证据。

<a id="v16"></a>

### V16. DiT、latent diffusion 与自回归视觉 token，分别解决什么问题？

- **难度 / 适用岗位：** 高级；图像生成、生成模型。
- **原创作答要点：** latent diffusion 在压缩空间迭代去噪；DiT 指用 Transformer 作为扩散去噪网络，不等同于语言模型的 next-token 目标。[DiT 论文](https://arxiv.org/abs/2212.09748)是基础入口。自回归路线需定义视觉离散化与序列因子分解。比较时控制分辨率、采样步数、编码器损失和条件信息；同时衡量视觉质量、文本对齐、计数、可编辑性与成本，FID 一项不足以反映用户需求。
- **深入追问：** 压缩编码器已经丢掉小字，后续生成骨干能否完全恢复？
- **常见误区：** 只要骨干是 Transformer，就认为训练目标和推理机制相同。

<a id="v17"></a>

### V17. 视频生成为什么不是把图像生成重复多次？

- **难度 / 适用岗位：** 高级；视频生成、世界模型。
- **原创作答要点：** 视频需要跨帧身份、运动、遮挡、镜头变化与因果一致性。可讨论时空 attention、时间模块、视频压缩和噪声调度，但需区分具体架构。[Stable Video Diffusion](https://arxiv.org/abs/2311.15127)强调图像预训练、视频训练与高质量数据阶段。评测要覆盖文本遵循、运动质量、长期一致性与人为挑样；视觉逼真不保证物理规律、可控交互或行动预测正确。
- **深入追问：** 单帧很清晰但物体数量随时间变化，怎样设计诊断集？
- **常见误区：** 把高观感视频直接称为可用于机器人规划的可靠世界模型。

<a id="v18"></a>

### V18. 如何为多模态服务做预算、批处理与线上回归？

- **难度 / 适用岗位：** 高级；多模态系统、技术负责人。
- **原创作答要点：** 以像素、帧、音频秒数、视觉 token 和输出长度共同建模成本；分离编码器、prefill、decode、传输与排队时延。动态分辨率和不同长度样本导致批处理不均衡，应限制输入并按长度调度。对 [Qwen3-VL](https://arxiv.org/abs/2511.21631)这类长交错上下文报告，要验证真实任务中的信息保留与资源曲线；支持的窗口上限不是推荐请求大小。回归集需含模糊、空白、损坏、多图、长视频与跨语言样本。
- **深入追问：** 文本 token 少但十张高分辨率图的请求，为何可能比长文本更慢？
- **常见误区：** 用文本上下文长度估算所有模态的成本，或只测模型温启动下的理想时延。
