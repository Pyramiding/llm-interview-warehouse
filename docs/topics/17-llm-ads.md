| 环节 | 数据 / 标签 | 传统基线 | LLM机制 | 上线指标 / 成本 |

### AB01. 广告链路中LLM应放在哪些环节？

- **难度 / 适用岗位：** 高级；广告算法、商业化排序、竞价与投放系统。
- **原创作答要点：** 区分广告主建计划、定向、候选召回、CTR/CVR排序、竞价、创意展示与归因。LLM适合语义特征、创意及辅助建计划；毫秒级竞价优先可校准的小模型和约束优化。先明确平台收入、广告主回报与用户负担的冲突，按环节做预算和消融。
- **深入追问：** 为什么不能让LLM每次直接报价格？
- **常见误区：** 把广告系统简化为文本生成。

### AB06. CTR、CVR、CTCVR的条件关系怎样写清？

- **难度 / 适用岗位：** 中高级；广告算法、商业化排序、竞价与投放系统。
- **原创作答要点：** 在同一曝光空间、转化须经点击且标签窗口一致时，P(点击且转化|x)=P(点击|x)P(转化|点击,x)。若含浏览后转化或跨设备漏链，不能硬套。ESMM提供全空间多任务思路；仍需检查概率校准、选择偏差、延迟反馈和埋点一致性。
- **深入追问：** 为什么直接拿两个独立模型概率相乘可能失真？
- **常见误区：** ESMM自动消除一切因果偏差。
- **一手机制参考：** [Entire Space Multi-Task Model: An Effective Approach for Estimating Post-Click Conversion Rate](https://arxiv.org/abs/1804.07931)。引用用于相应机制及方法入口；本题实验与业务设计为原创延伸。

### AB07. 延迟转化和归因窗口如何影响训练标签？

- **难度 / 适用岗位：** 高级；广告算法、商业化排序、竞价与投放系统。

### AB08. 负采样之后如何恢复可用于出价的概率？

- **难度 / 适用岗位：** 高级；广告算法、商业化排序、竞价与投放系统。
- **原创作答要点：** 保存各类样本保留概率与采样策略版本；均匀保留全部正例且负例保留率s时，样本概率q对应原概率p=sq/(1-q+sq)，条件是抽样仅依赖标签。简推：q=p/[p+s(1-p)]，解得上述p；非均匀抽样需使用对应保留概率和相应权重。用原分布留出集做分桶校准，分别看新广告与头部。
- **深入追问：** 困难负采样还可用同一公式吗？
- **常见误区：** AUC不变意味着出价概率可直接用。
- **一手机制参考：** [Nonuniform Negative Sampling and Log Odds Correction with Rare Events Data](https://arxiv.org/abs/2110.13048)。引用用于相应机制及方法入口；本题实验与业务设计为原创延伸。

### AB13. 广告增量评估为何不等于归因ROAS？

- **难度 / 适用岗位：** 高级；广告算法、商业化排序、竞价与投放系统。
- **原创作答要点：** 归因回答把已发生转化分给哪个触点；增量回答不投时会怎样。设计留出或随机抑制组，定义收益、成本、观察窗和污染处理，比较净增量而非目标组总购买。高自然转化人群可能归因漂亮但增量低；无法随机时明确识别假设。
- **深入追问：** 品牌词转化率高就应该无限投吗？
- **常见误区：** 购买倾向等于广告说服效果。
- **一手机制参考：** [Meta-learners for Estimating Heterogeneous Treatment Effects using Machine Learning](https://arxiv.org/abs/1706.03461)。引用用于相应机制及方法入口；本题实验与业务设计为原创延伸。

### AB17. 项目深挖：你如何解释AUC改善但广告收益下降？

- **难度 / 适用岗位：** 高级；广告算法、商业化排序、竞价与投放系统。
- **原创作答要点：** 按校准、样本选择、竞价价格、预算消耗、延迟标签及流量构成排查。回看同分布成熟标签集，检查概率放大是否导致出价过高；固定拍卖与预算做小实验。给出LLM特征消融、分桶结果、成本和负向案例，不用单个离线排序指标代替系统收益。
- **深入追问：** 是概率偏高还是流量变贵如何区分？
- **常见误区：** AUC提升必然增加收入。
