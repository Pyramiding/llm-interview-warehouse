### AA01. 怎样把大模型接入搜索全链路，而不是只在末端接一个问答框？

- **难度 / 适用岗位：** 高级；搜索算法、检索研究、排序与搜索架构。
- **原创作答要点：** 画出采集、解析、索引、query理解、召回、粗排、精排、答案及反馈。LLM可离线生成文档标签、线上理解复杂约束或重排小候选集。先按导航型、事实型、交易型分桶选瓶颈；保留倒排和双塔基线，分别估算收益、延迟与索引更新成本。
- **深入追问：** 导航查询是否需要答案生成？
- **常见误区：** 用最终答案的可读性代替搜索成功率。
- **一手机制参考：** [Transformer Memory as a Differentiable Search Index](https://arxiv.org/abs/2202.06991)。引用用于相应机制及方法入口；本题实验与业务设计为原创延伸。

### AA02. Query理解的意图、实体、槽位和硬约束如何共同建模？

- **难度 / 适用岗位：** 高级；搜索算法、检索研究、排序与搜索架构。
- **原创作答要点：** 将价格、地域、时间、否定词拆成有类型槽位，区分显式约束与推断偏好。训练集保留原query、会话和人工标注协议；LLM生成候选标签后抽样复核。评估槽位F1之外，增加约束违反率和对召回候选的影响；低置信歧义请求澄清。
- **深入追问：** “苹果换电池”怎样避免召回水果？
- **常见误区：** 把流畅的意图解释当作正确结构化理解。

### AA03. 如何证明query改写带来的是有效召回而非意图漂移？

- **难度 / 适用岗位：** 中高级；搜索算法、检索研究、排序与搜索架构。
- **原创作答要点：** 保留原始query通道，多路融合改写词、同义词及向量结果。构造否定、品牌、型号和日期最小对照集；固定召回预算比较Recall@K、约束满足率、无结果率。用人工相关性判断做盲测，记录每路新增相关文档与新增噪声，不能仅看词面相似度。
- **深入追问：** 多轮指代补全错了如何回退？
- **常见误区：** 改写越长、召回越多就越好。
- **一手机制参考：** [Active Retrieval Augmented Generation](https://arxiv.org/abs/2305.06983)。引用用于相应机制及方法入口；本题实验与业务设计为原创延伸。

### AA04. 倒排、双塔和生成式检索应怎样组合？

- **难度 / 适用岗位：** 高级；搜索算法、检索研究、排序与搜索架构。

- **深入追问：** 新增文档尚未进入参数时如何服务？

### AA07. LLM精排选pointwise、pairwise还是listwise？

- **难度 / 适用岗位：** 高级；搜索算法、检索研究、排序与搜索架构。
- **原创作答要点：** 比较独立打分、成对判断和列表排列，统一候选数、输入长度及预算。打分可缓存但需校准；成对成本随候选对增长；列表排序需测位置敏感、遗漏重复和滑窗融合。用候选置换测试稳定性，约束输出只含候选ID，并报告失败回退率。
- **深入追问：** 候选顺序变化导致排名翻转怎么办？
- **常见误区：** 自然语言解释充分就认为排序稳定。
- **一手机制参考：** [Is ChatGPT Good at Search? Investigating Large Language Models as Re-Ranking Agents](https://arxiv.org/abs/2304.09542)。引用用于相应机制及方法入口；本题实验与业务设计为原创延伸。
