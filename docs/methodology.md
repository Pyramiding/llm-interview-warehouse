# 来源与收录规则

[返回首页](../README.md) · [来源目录](source-catalog.md)

仓库从2026-10-22开始整理，以2023—2026年的公开面经为主，基础论文可以更早。资料通过检索和人工筛选补充，没有设置定期自动更新，也没有覆盖全网。

## 面经、练习和参考资料

- **面经**收在`data/interviews.json`。公司、岗位、轮次和结果均来自原作者自述，未向企业核实。一篇多公司复盘仍按一篇计。
- **专题题解和项目练习**依据论文、官方文档及工程实践编写，供复习和模拟问答使用。它们不是面经原题，也不是企业官方题库。题中的实验建议是练习设计，具体结论仍需实验验证。
- **参考资料**收在`data/resources.json`，包括题库、教程、二次解析和转载。它们单独统计，不算新增面试经历。

技术结论优先核对论文、作者仓库和官方文档。论文中的效果要连同模型、数据、预算和版本一起读；排行榜、价格、API参数和软件版本需在使用时重新确认。

## 页面读到了多少

| 数据中的状态 | 页面上的写法 | 含义 |
|---|---|---|
| `opened` | 已读正文 | 取得了相关正文；如果后半篇付费或附件未读，会在备注里写明 |
| `search_excerpt` | 仅搜索摘要 | 只核对了搜索结果中的标题或片段，没有取得全文 |
| `metadata_only` | 仅目录信息 | 只在发布者目录等页面找到标题和原链接，放在参考资料中 |

查阅记录表示当时的访问情况。链接后来打不开，可能是登录、反爬、网络或删除所致，需要再核对。仓库只整理公开可见内容，不补写付费墙或登录后未读到的问题。

## 日期怎么记

- `published`：能确定的页面日期。只有编辑日期时，在备注里说明。
- `published_at`、`updated_at`：取得首发和编辑元数据时分别保存，包含时区。牛客帖子使用原页`createTime`，动态使用`createdAt`。
- `event_date`：原帖提到的面试时间，可以是年月或一段时间。
- `year`：索引中的归组年份。年份不明用`null`，单列“年份未确认”。

“2026届秋招”可能发生在2025年，不能只看届次判断。只有月日、只有转载日期或只有编辑时间时，不猜精确面试日和首发日；按上下文推断年份的，会说明依据。论文的首发、修订和文档查阅日期也分别保留。

增量更新从上一次**资料提交**计算，工作流等配置提交不推进起点。晚发布的旧面试可以进入新发布批次，实际面试时间另记；按方向回补历史资料的批次会单独注明。页面显示的时间以原数据时区为准，当前带时间戳的面经均为北京时间。

## 公司和方向怎么分

平台按原链接所在网站分类。“小红书公司面试”和“小红书平台帖子”是两回事。

公司导航合并常用别名，条目保留原帖写法。多公司文章没有分清题目归属时，保留为一篇复盘。业务标签只根据可见岗位、项目或场景填写；候选人的旧项目不等于招聘团队的业务，这类情况在备注中说明。

`data/specialties.json`维护细分方向与已有记录的对应关系，生成[细分索引](interviews/by-specialty.md)和[LLM Infra页面](interviews/llm-infra.md)。同一篇可以出现在多个方向，但总数只计一次。暂缺面经的方向保留空列表；相关教程放在参考资料栏。

## 去重与计数

来源数按主`url`去掉追踪参数后统计。arXiv的abs、html、pdf和版本地址合并；LeetCode同一数值帖子ID下的slug与评论入口合并。旧Discuss地址、短链和新地址之间，只有确认跳转或同文后才合并。尚未识别的跨站镜像可能仍有重复，所以来源数是链接数，不是独立论文或候选人数。

已确认的同文链接放在`alternate_urls`；跨站转载也可以用`repost_reference`及`related_interview_id`连接主记录。它们不另外增加面经数。`content_fingerprint`保存去空白正文的SHA-256摘要，便于检查重复，不保存全文。

题目数只统计带固定编号的专题题和练习，追问不另算。`question_prompts`是少量改写的原帖问题，供快速浏览，不计入专题题解数量。各公司、方向的数量只是本仓库的收录情况，不能用来推算行业出题频率、招聘通过率或薪资。

## 补充资料时

先找原帖，核对标题、日期、公司、岗位和可读范围，再写摘要。公众号目录日期只作线索；没有读到原帖的小红书二手短链保留在检索日志中。有推广、付费截断、转载或归属疑问时，在原条目注明。

更新源数据后，用`tools/build_indexes.py`生成导航、题目索引、来源目录和统计，再运行结构及算例检查。具体步骤见[贡献说明](../CONTRIBUTING.md)。

采用短摘要和外链，不整篇搬运面经、付费答案或PDF。请勿提交私有题库、保密项目数据或个人信息。原作者如需更正署名、内容或移除链接，可以通过Issue提出。授权条款见[LICENSE.md](../LICENSE.md)。
