# 手写题与定量估算：16组原创练习

[返回首页](../../README.md) · [基础题](../topics/01-transformer-and-math.md) · [系统设计](projects-and-system-design.md)

题目为原创练习，手写方向可在[公开面经索引](../interviews/README.md)核对。建议先自己实现，写出输入输出、形状、复杂度与边界，再对照框架。提供的[纯Python示例](../../tools/interview_math.py)用于理解和小输入验证，不用于训练、GPU性能比较或实际服务。

<a id="h01"></a>

### H01. 实现数值稳定的softmax

**中；通用。** 对每个向量先减最大值，再做指数归一化。说明平移不变性，检查大正数、大负数、单元素。复杂度O(n)。NaN、正无穷、全负无穷要明确策略；本仓库参考实现拒绝非有限输入。不能认为直接exp在任意输入上都安全。

<a id="h02"></a>

### H02. 实现带causal mask的scaled dot-product attention

**中；算法/训练。** 明确Q/K/V为[n,d]，分数除以sqrt(d)，对未来位置设为不可见，再做行softmax与V加权。输入、mask、padding和cache位置索引必须一致；prefill与增量decode时Q/K长度未必相等。密集实现时间O(n²d)，注意力矩阵O(n²)。参考代码只演示等长单头自注意力。

<a id="h03"></a>

### H03. 把单头改成multi-head attention

**中；算法。** 给出[B,T,D]到[B,H,T,d_h]的变换，再合并回[B,T,D]；D需能被H整除。注意transpose后布局、输出投影以及mask广播。用固定随机输入与框架作数值对照；头数改变并不自动增加总隐藏维。

<a id="h04"></a>

### H04. 实现LayerNorm与RMSNorm

**中；基础/Infra。** 指定归一化的维度、epsilon放置和参数广播。LayerNorm中心化并计算方差；RMSNorm不减均值。测试常数向量、小幅值和低精度累加。不能把归一化后的样本一概称为服从标准正态分布。

<a id="h05"></a>

### H05. 实现RoPE的成对旋转

**中；基础/长上下文。** 说明head维度、频率、绝对位置和旋转配对约定。验证相同位置的旋转保点积、相对位置进入交互。增量解码的position offset要接续历史；不同实现的interleaved与split-half约定不能混用权重。

<a id="h06"></a>

### H06. 计算LoRA可训练参数与合并结果

**初/中；PEFT。** W形状为[d_out,d_in]，A为[r,d_in]、B为[d_out,r]，新增r(d_in+d_out)参数，更新通常为(alpha/r)BA。遍历目标层而非只算一块矩阵。验证B=0时初始输出保持；量化权重的反量化与合并会引入额外误差。

<a id="h07"></a>

### H07. 写DPO单样本loss的稳定计算

**中；对齐。** 先算策略与参考对chosen/rejected的序列对数概率差，再用负log-sigmoid。不能把所有token平均和所有token求和混为同一目标；需说明长度归一化是配方选择。测试偏好差增大时loss下降、零差时为log2。参考实现不包含神经网络或梯度。

<a id="h08"></a>

### H08. 实现top-k/top-p采样前的候选截断

**中；推理。** top-p按概率降序，保留累计概率首次达到p的最小前缀，再归一化；边界token应保留。说明先temperature还是先截断，测试p=1、并列值、单元素和无效p。排序通常O(VlogV)，top-k可用选择算法改善；固定seed是复现条件而非质量保证。

<a id="h09"></a>

### H09. 实现Recall@k、MRR与nDCG

**中；检索/评测。** 区分每query宏平均与按样本数加权。定义去重、无相关文档query、多个相关文档与分级相关性策略。MRR只关注首个相关命中，nDCG必须给出gain和discount。不要把文档召回分数直接当最终答案正确率。

<a id="h10"></a>

### H10. 写RRF融合并处理重复ID

**中；RAG。** 不同检索器的名次贡献为1/(c+rank)，同一列表的重复doc不应重复加分。说明截断深度、c与并列排序策略；测试某文档只出现在一个召回器的情况。RRF融合名次，不要求原始分数可比，也不保证总优于单路。

<a id="h11"></a>

### H11. 估算GQA的KV cache

**中；推理/Infra。** 常规每层独立缓存K/V时，字节约为2×层数×总缓存token数×KV头数×head维×每元素字节数。batch等长时总token=B×T；分页、共享前缀、量化scale、预分配和并行复制需另算。MLA、跨层共享或滑窗不能机械套用此式。

<a id="h12"></a>

### H12. 估算训练显存与优化器状态

**中；训练。** 分开权重、梯度、主权重、Adam一二阶状态、激活、通信buffer及碎片。某种BF16权重/梯度+FP32主权重与两状态的方案约16字节/参数，但实现可能无FP32主权重或保留FP32梯度。ZeRO只对对应状态分片，激活还受序列、batch、checkpoint和attention实现影响。

<a id="h13"></a>

### H13. 推导交叉熵与softmax的梯度

**中；算法。** 对独热标签有dL/dz=p-y；从logsumexp展开并说明batch/token归约。测试有限差分，处理ignore_index和有效token分母。梯度累积时不要每次只按不同大小的microbatch等权平均而误改目标。

<a id="h14"></a>

### H14. 实现一个小型BPE训练器

**中/高；数据。** 从词或字节的初始符号开始，统计相邻pair、合并最高频pair并记录顺序。定义边界、并列规则和训练/编码一致性。朴素每轮全扫描开销很高；真实实现需要增量更新。展示编码不等同于空格分词，训练语料分布影响切分长度。

<a id="h15"></a>

### H15. 实现带重试的工具状态机

**中/高；Agent。** 状态至少包括待执行、执行中、成功、可重试失败、最终失败和取消；记录调用ID、幂等键、超时与重试次数。模拟“服务已执行但响应丢失”，先查状态而不是再次写入；区分模型策略重试与基础设施重试。

<a id="h16"></a>

### H16. 实现流式JSON输出校验与回归回放

**中/高；应用/平台。** 处理半个UTF-8字符、未完成JSON、取消、字段错误和工具结果分批返回。语法正确后仍需schema与业务规则。回放固定模型、提示、工具stub和数据版本，记录结果及轨迹，不把非确定性工具结果当固定真值。补齐恶意字符串、超大输出与缺字段边界。
