## 专题与导航

八章各18题，均为原创研究延伸。每题提供岗位、难度、作答要点、追问、误区与一手机制来源；每章提供8行业务链路表，营销/风控/语音/客服另附项目验收证据清单。覆盖传统检索/排序/竞价/序列建模、因果与增量、训练数据及标签、在线链路、KPI、延迟与算力/预算约束，避免泛写RAG/Agent。

既有 `docs/interviews/by-company.md` 扩展为公司快速跳转页，统一常见别名，未明确公司与未逐公司归属记录单列。新增平台、岗位、年份和业务领域导航；README保留“全部公开面经合集”“按研究方向”“按公司”的跨公司范围语义。双字母新增题号不改变旧题号，生成器读取新来源片段，重复论文的topics并集保留各应用领域标签。
