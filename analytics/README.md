# 访问统计

网页仍由GitHub Pages发布，访问计数和IP记录由独立的Sites服务保存。

- [面经网页](https://pyramiding.github.io/llm-interview-warehouse/)
- [统计后台](https://llm-interview-analytics.givingalder513.chatgpt.site/)，通过ChatGPT登录，仅配置的所有者账号可以查看IP明细。

## 统计口径

累计访问和今日访问按页面载入计数，刷新另算一次；同一请求重试使用同一事件编号，不重复增加。今日IP数按北京时间和出口IP去重，同一IP可能对应多人。分类筛选、搜索和展开详情不另计一次访问。

统计从启用后开始，不补写历史访问。原始IP、访问时间和当时打开的资料类型保留最近30天；访问或查询统计时清理过期明细，累计次数与每日次数不含IP，继续保留。

不上传搜索词、收藏、完整页面URL、访客邮箱或浏览器指纹。页面提供停止后续记录的开关，也会尊重浏览器的Do Not Track和Global Privacy Control；这些情况下只读取公开的汇总次数。本地预览不发送统计请求。

## 数据与权限

IP取自服务端Cloudflare请求头，不接受浏览器传入的IP，也不使用客户端IP查询服务。拿不到可信访客IP时不写入明细；已知的共享代理占位IP不会记作访客。

采集请求限定网页来源，先取得短时、绑定出口IP的随机凭证，再提交记录；每个IP每分钟最多取得60个凭证。凭证不能跨IP、跨事件复用。匿名接口只返回总次数；明细接口必须通过平台登录，且邮箱匹配服务端的`ANALYTICS_OWNER_EMAIL`。该配置保存在Sites的保密环境变量中。

`site/analytics-config.json`只包含公开的服务地址和页面路径。生产数据库、实际所有者邮箱和凭据均不进入此仓库。浏览器中的统计可能被拦截器、隐私设置、网络失败或主动伪造请求影响，不能当作完整流量审计或精确人数。

## 维护

`backend/`保存服务的业务源码、数据库结构与迁移，和独立Sites源码库同步。Pages工作流只构建前端；修改后台后，需在对应Sites项目中运行类型检查、测试、数据库迁移生成与构建，再通过Sites发布。已应用的迁移不修改，后续变更新增迁移。

Sites项目ID为`appgprj_6aec434cf9208191916343f9c07c1a44`。保留现有项目和数据库，不要为普通更新新建服务。首次接入需设置`d1`绑定为`DB`、配置保密的所有者登录邮箱，并让采集接口可接收网页的匿名请求；管理员接口仍单独鉴权。

本库可以直接运行不依赖网络和真实IP的检查：

```sh
node tools/check_analytics.mjs
node --test analytics/backend/tests/analytics.test.mjs
```

后台测试使用内存数据库和保留的测试IP，不向生产环境写入演示访问。
